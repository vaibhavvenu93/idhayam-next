# Idhayam Next V3.1 — Founder approval preview

## What this is
An interactive browser-based concept, not a live matrimonial platform. All member identities, verification badges, revenue figures, events, concierge actions and conversations are simulated. No production identity verification, messaging infrastructure, payments, backend, or database is connected.

## Founder presentation (8–12 minutes)
1. Welcome: positioning and journeys.
2. Create profile: five-step onboarding and privacy preferences.
3. Discover: filtering, profile detail, shortlist and interests.
4. Connections / Messages: accepted-interest gating and sample chat.
5. Privé: concierge experience and membership positioning.
6. Government professionals and events: vertical differentiation.
7. Founder command centre: approvals, members, analytics, content, support.

Use **Founder walkthrough** on customer screens to navigate. Use **Load full sample journey** to seed a coherent demo, or **Reset demo** to clear browser state.

## Product direction decisions to seek
- Target segment and geographic launch market
- Matching preferences, consent, and moderation rules
- Privé pricing and concierge operating model
- Government professional eligibility and verification process
- Phase 1 launch scope, budget, timeline and owners

## Deployment
From the directory containing package.json: `npm install`, `npm run build`, `npm run dev`. For Vercel import as Vite, build command `npm run build`, output directory `dist`. This is a public static demo unless protected using deployment access controls. Do not enter real member data.
